# Scripts de ejemplo de edición

Estos scripts conservan el código utilizado para cortes, generación de gráficos, música, citas, efectos de sonido y modificaciones de un proyecto de CapCut. Los archivos multimedia, las transcripciones y los manifiestos específicos del video no se incluyen.

Son ejemplos de implementación, no comandos listos para ejecutar sobre cualquier proyecto. Adaptar rutas relativas, nombres de proyectos, tiempos, datos de entrada y dependencias antes de utilizarlos. Algunos scripts corresponden a pasos sucesivos y no son idempotentes.

La carpeta padre de `video-art` y `rough-cut` debe contener el kit en una subcarpeta `capcut-kit`, las entradas necesarias y, para los gráficos, el proyecto `motion-assets`. Los scripts conservan esa estructura de la sesión original.
